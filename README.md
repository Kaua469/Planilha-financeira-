# 📜 KADRON FINANCE — SaaS Premium

Sistema financeiro moderno, premium e escalável construído com as tecnologias mais avançadas do ecossistema Next.js.

## 🚀 Tecnologias

- **Framework**: Next.js 15 (App Router)
- **Estilização**: Tailwind CSS v4 + Shadcn UI
- **Animações**: Framer Motion
- **Banco de Dados & Auth**: Supabase
- **Gráficos**: Recharts
- **Relatórios**: React-PDF

## 🎨 Design System

Inspirado em Stripe e Linear, o sistema utiliza uma estética **Dark Mode Premium**:
- Fundo: `#07090D`
- Cor Principal: `#C80313` (Vermelho Kadron)
- Cards: `#151924`

## 📦 Funcionalidades

- **Dashboard Inteligente**: Visão geral de saldo, receitas e despesas.
- **Context Switcher**: Alternância global entre contexto Pessoal e Corporativo.
- **Onboarding**: Fluxo inteligente para novos usuários.
- **Relatórios PDF**: Geração automática de relatórios financeiros profissionais.
- **Gestão de Metas**: Acompanhamento de objetivos financeiros.

## ⚙️ Configuração

1. Clone o repositório.
2. Instale as dependências: `npm install`.
3. Configure o `.env.local` com suas chaves do Supabase.
4. Execute as migrações SQL disponíveis na pasta `supabase/migrations`.
5. Inicie o servidor: `npm run dev`.
